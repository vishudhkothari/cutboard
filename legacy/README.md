# Archived CUTBOARD / CUTIQ v1

This directory preserves the previous app, full workout tracker, calculation engine,
tests, persistence layer and supporting modules. Nothing here is imported by the
active app or included in the Vite entry point. ESLint excludes this historical code.

The archive is a reference snapshot, not a second supported application. The old
charting dependency was removed from the active package. Original remote data,
workout history, recipes, custom-food tables and progress-photo storage are not deleted.

Current implementation: `../src/`. Current architecture and research: `../docs/`.
